> [!NOTE]
>
> 目标：今日拉起整个vllm模型，如果只使用包的话，拉起还是比较容易的

创建一个conda 容器

```
conda create -n vllm python=3.12
conda activate vllm
pip install vllm
```

权重预下载在本地

```
# 走 hf-mirror 镜像
export HF_ENDPOINT=https://hf-mirror.com

# 禁掉 Xet（镜像不代理 CAS，必设，否则 401）
export HF_HUB_DISABLE_XET=1
export HF_XET_DISABLED=1

hf_download() { :; }
python - <<'PY'
from huggingface_hub import snapshot_download
snapshot_download("Qwen/Qwen2.5-1.5B-Instruct", local_dir="/root/Qwen2.5-1.5B-Instruct")
PY

# basic.py 里改成
llm = LLM(model="/root/Qwen2.5-1.5B-Instruct", trust_remote_code=False, ...)
```

然后需要加载模型

```
python /root/vllm/examples/basic/offline_inference/basic.py --disable-log-stats --model Qwen/Qwen2.5-7B
```

用的3080ti的卡

```
nvidia-smi --query-gpu=name,memory.total --format=csv
name, memory.total [MiB]
NVIDIA GeForce RTX 3080 Ti, 12288 MiB
```

出现out of memory 权重加载不下

![image-20260824231415340](images/image-20260824231415340-7584458.png)

换一个更小的模型

```python
llm = LLM(
    model="Qwen/Qwen2.5-1.5B-Instruct",
    trust_remote_code=True,
    gpu_memory_utilization=0.90,
    max_model_len=4096,
    enforce_eager=True,          # 关掉 CUDA graph，省显存
    # dtype="half",              # 如果还 OOM 就取消注释这行
)
```

```
python3 basic.py --disable-log-stats --model /root/Qwen2.5-1.5B-Instruct
```

![image-20260825005923684](images/image-20260825005923684-7590767.png)

拉起时长大概两分钟，目前看起来也不是很快

创建一个虚拟容器vllm-dev，并进入项目目录，去安装他的相关依赖

tmux终端配置

```
echo 'set -g mouse on' >> ~/.tmux.conf
tmux source-file ~/.tmux.conf

安装剪贴工具
apt install -y xclip
# 开启鼠标
set -g mouse on

# 复制模式用 vi 键位
setw -g mode-keys vi

# 复制到系统剪贴板（xclip 方式）
bind-key -T copy-mode-vi 'y' send-keys -X copy-pipe-and-cancel "xclip -selection clipboard"

```



```
conda create -n vllm_dev python=3.12 -y
conda activate vllm_dev
cd vllm
pip install -e . -v # 可以查看具体安装进程
```

安装包会出现安装不下的问题，将pip 路径更改到数据盘上

```
mkdir -p /root/autodl-tmp/pip_cache
export PIP_CACHE_DIR=/root/autodl-tmp/pip_cache
export TMPDIR=/root/autodl-tmp/tmp
mkdir -p $TMPDIR

# 确认生效
echo "PIP_CACHE_DIR=$PIP_CACHE_DIR"
echo "TMPDIR=$TMPDIR"

# 清 pip 缓存
pip cache purge

# 清 vllm 编译残留
cd /root/vllm
rm -rf build .deps .eggs *.egg-info
```
